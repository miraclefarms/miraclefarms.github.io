§1原则

底色守恒，accent 随板块换。

任何一页都该认得这是 MiracleFarms（同一张纸、同一套字、同一个五秆标志），又能一眼分辨在哪个板块（accent 不同）。

三条约束：① 纸面底色五板块共用，只换 accent / soft / tint；② 主站 data-section 与公众号 wechat_variant 一一对应、共用同一组 hex；③ 主标志只有一个（五秆），换色不换形。

Paper base

暖米纸 + 墨黑字 + 发丝分隔线。这一层永不随板块变化。

§3板块色板

五个板块，五种 accent。

左侧三色 = accent / soft / tint；右侧 = 该色落在真实组件上的样子。

§4主标志 · 五秆

一个标志，五种板块色。

五根高度不一的秆 = MiracleFarms 的五个板块。换色不换形：放进哪个板块的色块里，就染那个板块的 accent。

§5强度档位

同一组色，三档强度。

由 html[data-intensity] 控制，用户可在 Tweaks 面板切换。默认 medium。

§7Tokens

工程直接引用

页面在 <html> 上声明 data-section，即自动拿到该板块的 --sec-*。

assets/design-tokens.cssCSS variables
/* 共用底色（恒定） */
:root {
  --bg: #faf7f0;  --bg-card: #fffcf4;
  --ink:#2c2a26;  --rule: rgba(44,42,38,.14);
}
/* 板块 accent —— 只换这三档 + 引文色 */
html[data-section="readings"] {
  --sec-accent:      #3d5168;
  --sec-accent-soft: #6b7e98;
  --sec-tint:        #e3e8ef;
}
/* 用法 */
.pill.primary { background: var(--sec-accent); }
.tag          { background: var(--sec-tint); }
