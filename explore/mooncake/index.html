04 / TWO STORE DESIGNS

同一类对象 API，两种控制面

当前源码同时存在经典 C++ Store 和 Rust 原生 Store。先确认自己用的是哪一条实现，再讨论元数据、故障恢复和部署。

经典 C++ Store

Master 决定放置与可见性

Client → Master → 副本描述符
Client ═══ TE / TENT ═══ Storage Client

集中管理对象目录、分配、租约、配额与副本状态。数据传输绕过 Master。

Rust 原生 Store

Authority mesh 管理对象路由

Client → WRH authorities → Route
Client ═══ TE / TENT ═══ Storage Owner

默认 EmbeddedWrh 通过租约快照选路由权威节点，用 CAS 发布路由；没有专用 Master 在正常路由热路径上。

C++ Store 与 Rust Store 架构对比
